# Yeaseen.github.io
My Personal portfolio website built with Jekyll (projects, research, teaching, blog, and activities).

## Run from a fresh machine

### 1) Install required tools
- `git`
- `ruby` (3.x recommended)
- `bundler` (`gem install bundler`)

### 2) Clone and install dependencies
```bash
git clone https://github.com/Yeaseen/Yeaseen.github.io.git
cd Yeaseen.github.io
bundle install
```

### 3) Start locally
```bash
bundle exec jekyll serve
```

Open: `http://127.0.0.1:4000`

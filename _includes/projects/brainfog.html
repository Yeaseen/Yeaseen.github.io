Brainfog: Realizing Brainfuck PL

Tools: C, GCC, x86-64, JIT, LLVM, CMake

Brainfog is a systems programming project where I built and optimized a full Brainfuck execution stack. It started with a high-performance C interpreter, then evolved into an x86-64 compiler pipeline with loop optimization, lightweight profiling, and SIMD-style improvements. The latest stages add a JIT engine and an LLVM-based backend.
